🎯 CASOS DE USO
═════════════════════════════════════════════════════════════════════════════

  Usar en producción:
    python main.py

  Extender con nueva restricción:
    - Edita src/optimization.py (agregar constraint al ILP)
    - Edita config.py (si necesita nuevo parámetro)
    - No toques main.py

  Testear función individual:
    from src.time_utils import hhmm_to_min
    assert hhmm_to_min("08:30") == 510

  Exportar a base de datos:
    - Copia io.export_dataframe()
    - Crea io.export_to_database()
    - Llama desde main.py
